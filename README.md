# Autonomous Cyber Defense Engineering Lab (ACDRL)

**Research mission:** Autonomous Cyber Defense and Resilience Engineering for Spacecraft and Critical Financial Infrastructure.

ACDRL is an independent applied research and engineering initiative investigating how AI-based detection and adaptive defensive decisions can protect mission-critical systems while respecting safety, availability, and operational constraints.

## Research sequence
1. **Spacecraft and ground-segment systems:** architecture, threat modeling, isolated simulations, detection baselines, and safe adaptive defense.
2. **Financial critical infrastructure:** independent evaluation of which methods transfer to simulated payment-system environments, and which do not.

## Research method
Problem → Literature → Research question → Hypothesis → Mathematical model → Simulation → Baselines → Experiment → Evaluation → Evidence → Publication or prototype.

Research claims must be supported by reproducible experiments and a documented comparison to relevant prior work. This repository does not claim operational validation or novelty before evidence is available.

## Safety and data
Only authorized, isolated simulations and legally usable data are in scope. Never commit credentials, sensitive operational configurations, confidential financial records, or restricted spacecraft information. Do not target operational satellites, ground stations, or payment systems.

## Status

## Reproducibility
Each experiment will record its ID, protocol, environment, code commit, dataset provenance, parameters and seeds (where applicable), baselines, metrics, results, and limitations.
