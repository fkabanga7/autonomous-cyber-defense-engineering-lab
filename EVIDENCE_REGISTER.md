## Evidence classes
- **Scientific:** protocols, hypotheses, mathematical models, controlled comparisons, statistics, limitations.
- **Engineering:** simulation code, tested components, architecture, CI, documented prototypes.
- **Reproducibility:** Git commits, dependencies, seeds, provenance, logs, dataset hashes, run instructions.
- **Dissemination:** manuscripts, presentations, published papers, releases.
- **Independent impact:** independently verifiable citations, use, collaboration, evaluation or adoption, if obtained.

## Communication rules
1. Publish only results actually obtained and checked.
2. Distinguish simulation findings from live operational validation.
3. Never publish secrets, sensitive vulnerabilities, restricted mission details, or confidential financial information.
4. A LinkedIn post may describe a completed milestone, not imply scientific novelty or peer review.
5. An EB-2 NIW evidence package may reference documented work but must not equate publication volume with immigration eligibility or guarantee an outcome.
